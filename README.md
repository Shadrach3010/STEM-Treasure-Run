# STEM Treasure Run

A small beginner-friendly Python game built with Pygame. Collect ten STEM
coins while avoiding the rocks. Each coin is worth 10 points, and touching a
rock costs one of the player's three lives.

## Controls

- Arrow keys: move the player
- `R`: restart after winning or losing
- `Esc`: quit

## Run the game

Install Python 3, open a terminal in this folder, and run:

```powershell
py -m pip install -r requirements.txt
py main.py
```
